# Deploy InsightGuard AI to Netlify

## Fastest method: Netlify Drop

1. Extract the final ZIP.
2. Open [Netlify Drop](https://app.netlify.com/drop).
3. Drag the extracted `insightguard-mvp` folder onto the page.
4. Wait for the deploy to finish, then open the generated HTTPS URL.
5. Test **Explore live demo**, **Upload Data**, **AI Insights** and **Billing** on the public URL.

There is no build command. The included `netlify.toml`, `_redirects` and `_headers` files are already configured for static hosting.
